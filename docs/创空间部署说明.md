## 配置和启动

1. 将本轮确认后的代码同步到已有创空间。至少包含根 app.py、pages、app、src、configs、demo_assets、三个 requirements 文件和 .streamlit/config.toml，不能只上传入口文件。
2. 保持 Streamlit 类型、Python 3.12，入口为根目录 app.py。平台负责运行 Streamlit，不要用 python app.py 启动，也不需要切换成 Docker。
3. 在创空间变量中设置 CREDIT_RISK_PUBLIC_DEMO=1。公开展示模式保留预测、解释、规则和对比，禁止在线训练、真实数据上传、配置保存和真实 DeepSeek 调用。
4. 平台从独立的根 requirements.txt 安装，固定版本与 requirements-review.txt 和 app/requirements.txt 保持一致，不依赖构建临时目录之外的文件。首次安装 CPU 版 PyTorch 仍需下载，请查看构建日志是否安装成功。
5. 重新部署，看到 Running 后再访问页面。若失败，保留日志最后的异常，不要反复无条件重启。

本机模拟相同入口：

```powershell
cd D:\credit_risk_system3
$env:CREDIT_RISK_PUBLIC_DEMO = "1"
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address=127.0.0.1 --server.port=8505
```

## 使用本地训练的模型

默认加载仓库现有的 demo_assets/bundle.joblib。本机 data/models/latest 不会自动上传；改变代码也不会重新训练模型。

需要使用另一份训练结果时，把可信的完整 bundle.joblib 放到创空间运行环境可访问的目录，在创空间变量中设置：

```text
CREDIT_RISK_MODEL_PATH=/mnt/workspace/models/bundle.joblib
CREDIT_RISK_PUBLIC_DEMO=1
```

也支持相对于项目根目录的路径。本机可把 CREDIT_RISK_MODEL_PATH 临时设置为 data/models/latest/bundle.joblib，对照预测结果。未设置时，原来的模型选择方式保持不变；设置的文件缺失、损坏或格式不兼容时会显示错误，不会自动换成其他模型。

必须使用当前项目保存的完整模型包，它包含预处理、特征构造与选择、各模型和页面所需的评估信息。只上传 xgb_model.json 或 mlp_model.pth 不能让整个网站工作。云端使用 CPU，模型也应在相同固定依赖的 CPU 环境保存。

本次检查到本机 latest 的元数据仍为合成数据训练结果：训练 3,500 条、验证 500 条、测试 1,000 条，还不是后来放入的真实数据训练结果。本轮没有改动数据、重新训练或替换模型。

真实数据训练的完整包还含解释样本、监控基线及 KNN 参考记录，应放在受控的运行环境或私有存储中。不要把它直接加入公开 GitHub、公开创空间代码库或 demo_assets；.env、真实 CSV、.local 账本也不上传。
