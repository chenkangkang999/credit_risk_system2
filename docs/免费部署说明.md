# 免费公开展示部署说明

用户已授权代码检查通过后上传 GitHub；公网展示尚未发布。当前 http://127.0.0.1:8503 只用于本机查看。

## 部署选择

使用 Streamlit Community Cloud，不购买服务器或域名，使用平台提供的 streamlit.app 子域名。

官方说明：
- https://docs.streamlit.io/deploy/streamlit-community-cloud
- https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy
- https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/app-dependencies

免费平台可能休眠或受资源限制；实际部署后应在老师和同学使用的网络环境验证。

## 部署操作

1. 核对远端 main 的新提交，保留同学改动。
2. 检查修改清单和密钥扫描结果，明确本次要上传的文件。
3. 使用中文备注提交本次代码，再推送到现有 main。不创建新分支，不使用强制推送。
4. 用户登录 Streamlit Community Cloud，选择项目组现有仓库、main、入口 app/streamlit_app.py。
5. 选择 Python 3.12。依赖使用 app/requirements.txt，其引用 requirements-review.txt 并安装 CPU 版 PyTorch。
6. 保留 demo_assets 中的合成数据和演示模型。不要提交 .env、.local、真实 CSV、日志或私人模型。
7. 不填写 DeepSeek Secret。公开站点默认处于展示模式，不调用真实 API，不提供训练、上传或配置保存。
8. 部署后检查首页、单笔预测、解释图、规则检查、A/B 和情景对比，再把实际可访问链接交付用户。

平台优先读取入口目录中的依赖文件，因此原有根目录 requirements.txt 可以保持不变。packages.txt 提供 Linux 的 OpenMP 和中文字体。

## 公共模式在本机检查

在新的 PowerShell 窗口运行：

    cd D:\credit_risk_system3
    $env:CREDIT_RISK_PUBLIC_DEMO = "1"
    .\.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py --server.port=8504

关闭该窗口后此环境变量失效。公开模式无论本地是否配置密钥，都禁止调用 DeepSeek。
