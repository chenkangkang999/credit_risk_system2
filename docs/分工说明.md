# 项目分工说明

## 大体分工

- **chenkangkang999**：主要负责数据处理、模型算法、调参、模型解释和漂移检测，以及真实数据的准备和接入。
- **MeteorShower7**：主要负责衍生特征、特征选择接入、训练和预测流程、DeepSeek 智能功能，以及网页和扩展功能。

## 具体分工

| 工作 | chenkangkang999 | MeteorShower7 |
|---|---|---|
| 数据处理 | 清洗数据、填补缺失值，适配并合并天池和 Lending Club 数据，增加真实数据入口。 | 在页面中使用这些数据，修复数据切换、缓存和加载失败的问题。 |
| 特征处理 | 提供基础特征构造和特征筛选代码。 | 增加业务衍生特征，把特征选择接入训练和预测，保证使用同一套筛选结果。 |
| 模型训练与融合 | 实现 XGBoost、LightGBM、MLP 和融合模型，设置三模型权重。 | 串起训练、评估、保存和预测流程，将三种模型实际接入融合。 |
| 模型调参 | 实现自动调参和 AUC、KS 等调参目标。 | 在训练页面接入调参选项，展示训练和评估结果。 |
| 解释与监控 | 实现 SHAP 解释和数据漂移检测。 | 展示解释图、监控结果，增加风险情景对比。 |
| DeepSeek 智能功能 | 提供初始项目结构。 | 完善对话、风险报告、特征建议、异常分析、政策合规检查，以及 Token 和费用展示。 |
| 网页功能 | 提供初始页面和真实数据加载入口。 | 完善各页面和侧栏，增加 A/B 测试、模型监控和情景对比页面。 |
| 测试与说明 | 维护基础模块和数据适配测试。 | 补充功能和联调测试，整理使用、答辩、部署及分工说明。 |
